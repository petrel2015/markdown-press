# 隐私

MD·PRESS 存储什么、发送什么、请求什么——逐项对照源码核实（2026-08-27）。
English: [privacy](../en/privacy.md)。

## 摘要

应用是一组静态文件。没有后端、没有账号、没有分析统计。它触碰的唯一数据
是你输入的文字，保存在浏览器的 `localStorage` 里。唯一的运行时网络流量
是同源的（应用自己的文件，包括对 vendored mermaid 库的一次性懒加载）。

## 存储了什么

全部持久化都在 `localStorage`，作用域是浏览器中的站点源。除此之外不存储
任何内容；没有 cookie。

| 键 | 内容 | 写入时机 | 生命周期 |
|----|------|----------|----------|
| `mdpress-doc` | 文档文本（明文） | 停止输入约 400ms 后；页面卸载时；打开文件 / 新建时 | 直到清除站点数据或替换文档 |
| `mdpress-name` | 文档基础名 | 随文档一起 | 同上 |
| `mdpress-lang` | 界面语言（`en` / `zh`） | 切换语言时 | 直到清除 |
| `mdpress-mode` | 视图模式（`edit` / `split` / `preview`） | 更改模式时 | 直到清除 |
| `mdpress-split` | 分屏比例百分数 | 分割条调整结束约 300ms 后 | 直到清除 |

每处访问都有 `try/catch` 包裹：存储被封锁（隐私模式、配额）时应用在内存
中继续运行，不持久化任何内容。

在浏览器中清除站点数据将永久删除文档——没有服务器副本。

## 网络行为

通过逐行阅读所有触碰网络的代码、以及在浏览器中以空网络日志完整走查
UI 会话核实：

- 首次加载：浏览器从站点源取回应用自身的静态文件（HTML、CSS、JS、
  vendored 库）。
- 一次性懒加载：当文档首次包含 ` ```mermaid ` 围栏时，应用注入
  `vendor/mermaid.min.js`——**同源**文件，属于本仓库。没有图表的文档
  完全不加载；`file://` 下则完全不加载。
- 仅此而已。**没有**第三方主机、**没有** CDN 字体、**没有**分析或
  遥测、**没有**版本检查、**没有**错误上报。

你嵌入的图片由浏览器从其指向的位置取回（`<img>` 的正常工作方式）；除
上述两类外，应用自身不发起任何请求。

## 第三方

- 运行时，应用不联系任何第三方。
- 文档内的外部链接被点击时在新标签页打开——目标站点看到的是来自你
  浏览器的一次普通访问。
- 托管方（在线 Demo 为 GitHub Pages）负责伺服文件，必然会记录涉及的
  请求；这不属于本项目可控范围。要完全本地使用，可下载仓库后从磁盘或
  自有服务器打开。

## 浏览器权限与对话框

| 请求 | 时机 | 范围 |
|------|------|------|
| 文件选择器 | `打开 .md` | 仅本地读取你选中的文件（经 `FileReader`）；不上传 |
| `confirm()` 对话框 | `新建` 文档 | 浏览器内置对话框 |
| `prompt()` 对话框 | 插入链接 | 浏览器内置对话框，询问 URL |

从不请求地理位置、通知、摄像头、麦克风、剪贴板或其他任何权限。导出均
为普通本地下载。

## 安全说明

- mermaid 以 `securityLevel: 'strict'` 运行（标签被净化、点击交互被
  禁用）。
- 渲染后的 Markdown 走 marked 12 的无消毒管线，但自定义代码渲染器对
  围栏内容做了转义；粘贴不可信内容时，请像对待任何 Markdown 渲染器
  一样保持警惕。

## 诚实边界

本页描述的是**本仓库代码**的行为，无法替你的浏览器、操作系统或托管方
背书。这里的每条声明都可在源码中验证：存储键位于 `js/app.js`、
`js/i18n.js`、`js/layout.js`；网络注入位于 `js/markdown.js`；文件处理
位于 `js/export.js`。
