# 使用说明

如何一步步操作 MD·PRESS。项目定位见 [README](../../README.md)；边界行为
背后的设计原因见[功能设计](./features/index.md)与[架构](./architecture.md)。
English: [usage](../en/usage.md)。

## 首次启动

1. 打开应用（在线 <https://petrel2015.github.io/markdown-press/>；本地
   `open index.html` 或经静态服务器访问）。
2. 载入本地化的示例文档，涵盖标题、列表、表格、代码与 Mermaid 流程图。
   示例会立即存入 `localStorage`，刷新后仍在。
3. 界面语言默认跟随浏览器语言；可用顶栏的 EN / 中文 按钮切换，选择会被
   记住。

## 书写

### 视图模式

- **编辑** —— 只显示编辑器。
- **分屏**（桌面默认）—— 左编辑，右预览。
- **预览** —— 只显示预览。

用品牌下方的 编辑 / 分屏 / 预览 标签切换，选择会持久化。视口窄于 768px
时分屏不可用：应用将其强制转为编辑并隐藏该选项（见[手机上](#手机上)）。

### 分割条

- 拖拽两窗格之间的分割条；分屏比例钳制在 25%–75%。
- 分割条可聚焦（它是可键盘到达的分隔器）：`←` / `→` 每次调整 2 个
  百分点。
- 双击复位 50 / 50。
- 比例在调整结束约 300ms 后持久化。

### 格式化

编辑器上方的工具栏在选区周围插入或切换语法：加粗、斜体、代码、链接
（弹窗询问地址）、列表（对选中行切换 `- ` 前缀）、图表（插入 Mermaid
起始围栏）。

键盘快捷键（编辑器聚焦时）：

| 快捷键 | 动作 |
|--------|------|
| `Cmd/Ctrl + B` | 加粗 |
| `Cmd/Ctrl + I` | 斜体 |
| `Cmd/Ctrl + K` | 插入链接 |
| `Enter`（列表内） | 续行列表 |

当选区已带有标记时，加粗与斜体会切换取消。

### 图表

标记为 `mermaid` 的围栏代码块渲染为 SVG 图表：

    ```mermaid
    flowchart LR
      A --> B
    ```

- 图表随预览其余部分一起重新渲染（约 300ms 防抖）。
- mermaid 库（约 3.3 MB）在文档首次包含图表时按需加载一次；没有图表的
  文档完全不加载。
- 非法的图表语法会在原码上方显示红色"图表语法错误"标签——页面其余部分
  不受影响。修正语法后重新渲染。
- 图表需要页面经 `http(s)` 访问。`file://` 下保持原码（见
  [故障排查](./troubleshooting.md#图表显示为源码)）。

## 文件

### 打开本地文件

`打开 .md` 打开文件选择器，接受 `.md`、`.markdown` 与 `.txt`。内容会
替换当前文档（替换前当前文档已自动保存，因此原文档在存储中被覆盖），
文件名（去扩展名）成为文档名，用于所有导出。

### 下载源文件

`下载 .md` 将原始 Markdown 保存为 `<文档名>.md`。文件名中的非法字符
（`\ / : * ? " < > |`）替换为 `_`；缺少扩展名时自动补 `.md`。

### 自动保存与存储

- 文档在停止输入约 400ms 后以及页面卸载时存入 `localStorage`；状态栏
  显示保存时间。
- 同时持久化：文档名、语言、视图模式、分屏比例。
- `localStorage` 不可用时，一切功能照常在内存中运行——只是不持久化，
  也不会报错。
- 没有服务器副本。在浏览器中清除站点数据即删除文档。`新建`（确认后）
  立即清空。

## 导出

所有导出均在本地生成并下载；不会上传任何内容。导出文件名跟随文档名：
`<名称>.pdf` / `<名称>-phone.png` / `<名称>-a4.png` / `<名称>.md`。

### A4 PDF（打印）

1. `导出` → `A4 · PDF（打印）`。预览被克隆进仅打印容器，浏览器打印
   对话框打开。
2. 目标选择**存储为 PDF**。
3. 边距与分页由浏览器控件加上内置 `@page` 规则决定；标题不与后文跨页
   分离，代码块、表格与图表尽量不跨页截断。
4. 文字保持矢量、可选——这正是 PDF 路径走打印对话框而非栅格化的原因。
5. 打印完成（或关闭对话框）后，打印容器被清空、文档标题被还原。即使
   浏览器不回报打印完成，60s 的兜底定时器也会清理。

### 手机长图（PNG）

`导出` → `手机长图 · PNG` 以 390px 逻辑宽度（2× 输出 780px）、20px
内边距将整个渲染后的文档栅格化——一张适合手机屏幕查看的长图。

### A4 图片（PNG）

`导出` → `A4 图片 · PNG` 以 794px 逻辑宽度（2× 输出 1588px）、60px
内边距栅格化——PDF 的图片替代方案。

### 导出中的图片

本地图片与 data-URI 图片可正常导出。被 CORS 拦截的远程图片无法进入
PNG 导出（见
[故障排查](./troubleshooting.md#远程图片未出现在-png-导出中)）。

## 语言

- EN / 中文 切换会立即重标全部界面文案、更新页面标题、`lang` 属性与
  ARIA 标签，并替换首启动示例文档文本。
- 选择持久化在 `localStorage` 中，之后的访问优先于浏览器语言检测。

## 手机上

视口窄于 768px 时应用切换为单窗格标签：编辑 / 预览（分屏隐藏）。格式化、
导出与语言控件仍在顶栏和工具栏可用。旋转屏幕与调整窗口无需刷新即可
自适应。

## 错误处理

| 情形 | 行为 |
|------|------|
| Mermaid 语法错误 | 红色"图表语法错误"标签 + 显示原码；页面不受影响 |
| 导出目标缺失（如 html-to-image 加载失败） | 状态栏提示"导出失败——详情见控制台。"；不产生下载 |
| PNG 栅格化出错 | 同上失败提示；细节记录在浏览器控制台 |
| `打开 .md` 扩展名不受支持 | 状态栏提示"仅支持 .md、.markdown 或 .txt 文件。"；不载入 |
| 文件无法读取 | 状态栏提示"无法读取该文件。" |
| 某启动阶段失败 | 状态栏提示"部分功能启动失败——请刷新页面重试。"；其余阶段照常运行 |
| `localStorage` 不可用 | 静默回退为内存模式；不持久化 |
| PNG 导出中图片始终不加载 | 每张图片等待 4s 后继续导出 |

提示显示在状态栏（右侧），4 秒后自动消失。

## 边界行为

- 一次只处理一个文档；没有文档列表或标签页。
- `新建` 不可撤销——确认对话框后立即清空。
- 预览为只读；点击链接按普通方式打开（与编辑器无联动）。
- 分屏比例在旋转屏幕后保留；视口跨越手机断点时模式本身会被重新强制
  转换。
- `滚动同步` 只在分屏模式下生效。
- 自动保存只写入本地——有意不提供同步、备份或 `localStorage` 之外的
  历史版本。
